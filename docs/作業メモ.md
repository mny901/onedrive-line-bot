# 作業メモ（Lightsail での運用手順）

当時の手元メモを整理したものです。サーバーの IP アドレスや鍵ファイルのパスは伏せ字にしています。

## サーバー上の場所

- プロジェクトの場所: `/home/ubuntu/onedrive_line_bot`
- venv を有効にする: `source venv/bin/activate`
- venv を無効にする: `deactivate`

## 手元からファイルを差し替える（PowerShell）

```powershell
scp -i "<鍵ファイルのパス>\LightsailDefaultKey-ap-northeast-1.pem" `
    main.py .env `
    ubuntu@<LightsailのIPアドレス>:/home/ubuntu/onedrive_line_bot/
```

## 手元から Lightsail に入る

```powershell
ssh -i "<鍵ファイルのパス>\LightsailDefaultKey-ap-northeast-1.pem" ubuntu@<LightsailのIPアドレス>
```

## 実行時刻を変える

```bash
crontab -e
```
